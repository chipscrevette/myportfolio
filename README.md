# Portfolio

Une page, quatre projets : Orbi, Les Arpenteurs, La cuisine de l'IA et LeBron James 2017-18.

Site statique, sans build. Ouvrez `index.html`, ou servez le dossier :

```sh
python3 -m http.server
```

- Français et anglais, mode jour et nuit (le choix est retenu par le navigateur).
- Polices Geist et Geist Mono, servies par Google Fonts.
- Les mascottes viennent des dépôts de chaque projet ; la courbe de LeBron est tracée avec les vraies données du dépôt `d3_exploration`.
